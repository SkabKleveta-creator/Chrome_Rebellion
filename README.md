# Chrome Rebellion

A cybernetic street brawler with four playable fighters: RAM, VEX, WARD, and WIRE.

[Play Chrome Rebellion](https://skabkleveta-creator.github.io/skab-digital-reality-arcade/games/chrome-rebellion/) · [Visit the arcade](https://skabkleveta-creator.github.io/skab-digital-reality-arcade/)

Open `index.html` in a modern browser or serve this directory with a static web server. The game is contained in one HTML file. Google Fonts are optional external styling resources with local font fallbacks.

## Controls

WASD/arrows move; double-tap a direction to run. J/Z: light attack. K/X: heavy attack. Space/C: jump. L/V: grab, pick up, or throw. I/B: special. U/Shift/N: dodge; hold with no direction to guard. Esc/P/Enter pauses. Touch controls and gamepads are supported.
